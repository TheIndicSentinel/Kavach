# Operations in docs/openapi.yaml that console/src does not call, and why.
# Checked by scripts/console_path_coverage.py (CI, "Console API path coverage"):
# an operation the console neither calls nor lists here fails the check, and
# so does a line here whose operation is gone from the spec or that the
# console now calls.
#
# One operation per line: METHOD /path reason

GET /metrics Prometheus text format for Prometheus and Grafana (deploy/monitoring/), with an operator token allowed read_metrics; the console has no metrics view.
POST /v1/dev/clock Development stacks only (404 unless started with `kavach dev up --clock`); driven by the kavach CLI (dev, simulate, attack), never by an operator in the console.
POST /v1/authorize Agent listener: an agent's pre-check, with an agent token; not on the operator listener the console talks to.
POST /v1/tools/{tool} Agent listener: an agent's tool call through the gateway, with an agent token; not on the operator listener the console talks to.
POST /v1/sor/events System-of-record listener (backend network only): signed events from the lender's systems; not on the operator listener the console talks to.
GET /v1/change-requests/{id} The Change requests page reads requests from GET /v1/change-requests, whose items are the same ChangeRequest; the console has no view of one request by id. Outside kavach-api's own tests, nothing in the tree calls this read.
GET /auth/callback The IdP redirects the browser here after sign-in (ADR-018); the console never calls it, the browser follows the redirect.
